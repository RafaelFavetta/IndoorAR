Trabalho de Conclusão de Curso de Desenvolvimento de Sistemas da ETEC, em uma equipe de 3 pessoas. Ele tem como objetivo o desenvolvimento de um aplicativo mobile para localização indoor, uma solução prática para navegação em ambientes fechados e em grandes estruturas como shoppings, hospitais, museus, aeroportos, entre outros. O foco principal da aplicação é solucionar a perda de tempo e a dificuldade de orientação em locais desconhecidos.

Para uma compreensão completa do aplicativo, abordaremos as técnicas utilizadas em seu desenvolvimento, incluindo aspectos de design gráfico e outras ferramentas empregadas. O aplicativo será construído utilizando a linguagem de programação Kotlin e utilizará realidade aumentada(AR).

A solução proposta terá duas interfaces principais: uma para o usuário final e outra para o criador de mapas. A ideia é simplificar a criação e visualização dos mapas por meio do uso de formas geométricas básicas, como quadrados e retângulos, para representar os ambientes reais. Essa abordagem simplificada torna o projeto viável e acessível, permitindo seu desenvolvimento de maneira gratuita.

As principais funcionalidades do aplicativo incluirão: 
- **Criação de mapas**: Utilização de formas geométricas simples para a criação de mapas, permitindo uma representação eficiente e intuitiva dos espaços internos. (Funcionalidade semelhante ao Figma)
- **GPS**: Sistema de localização para guiar o usuário dentro do ambiente.
- **AR**: Exibição da rota em realidade aumentada na própria câmera do dispositivo para um desempenho mais prático e interativo.
- **Mapa**: Exibição de um ícone de localização que permitirá a busca por mapas já cadastrados no aplicativo.
- **Download de Mapas**: Função para download de mapas, permitindo o acesso offline em caso de perda de conexão Wi-Fi. (Função secundária caso sobre tempo)

Serão realizados testes em ambientes reais, com o objetivo de fornecer uma visão prática sobre a aplicação, demonstrando sua eficácia em diferentes dispositivos móveis, como celulares e tablets.
Embora já existam aplicativos como Google Indoor e GPS Indoor, esses serviços não são amplamente conhecidos ou utilizados no cotidiano. De acordo com uma pesquisa realizada, 70,6% dos entrevistados nunca ouviram falar sobre essas ferramentas, e 94,1% nunca as utilizaram.
